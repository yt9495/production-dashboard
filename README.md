# 생산 가동율 관리 시스템 (HF / HNO3 / HCl)

월별 실제 생산량을 입력하면 생산 Capa 대비 가동율(%)을 대시보드로 보여주는 웹앱입니다.

- 대시보드: 기간 지정 조회, 월별 가동율 트렌드, 생산량 vs Capa, 월별 보고서 및 인쇄
- - 데이터 입력: 월별 HF / HNO3 / HCl 실제 생산량(kg) 입력
  - - 설정: 월 생산 Capa 변경 (기본 HF 372,000 / HNO3 204,600 / HCl 204,600 kg)
